# Tasks During Internship at HindukushSoft

This repository holds all the work completed during my 2-month internship at HindukushSoft. It's organized by day, with each folder containing that day's task or exercise, plus a dedicated folder for the final capstone project.

## Repository Structure

```
Tasks-during-Internship-at-HindukushSoft/
  Day1  ... Day36Plan/   → Daily tasks and exercises completed throughout the internship
  first/                 → Early practice/setup work
  FullStackCCA/           → Final capstone project: CCA (Chitral Coaching Academy)
```

Each `DayX` folder corresponds to a specific day's assignment during the internship — these track progress from early exercises through to more advanced tasks as the internship went on.

## Main Project: FullStackCCA

The capstone project built during this internship is **CCA (Chitral Coaching Academy)** — a full-stack online learning platform where instructors create courses, students enroll and learn, and an admin manages the platform.

**Tech stack:** Laravel (backend/API) · MySQL (database) · React (frontend)

```
FullStackCCA/
  online-learning-backend/   → Laravel API
  online-learning-frontend/  → React app
```

See the [`FullStackCCA`](./FullStackCCA) folder for the full project, including setup instructions, API routes, and features, in its own README.
